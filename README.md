# Estudos de Python

Exercícios de programação orientada a objetos e desenvolvimento de um jogo com a biblioteca Turtle.

## Projetos

| Arquivo | Conteúdo | Execução |
| :--- | :--- | :--- |
| [conta.py](./conta.py) | Exercício de classes e métodos com operações de uma conta bancária | `python conta.py` |
| [teste01.py](./teste01.py) | Snake: movimento, colisões, pontuação e geração de comida | `python teste01.py` |

## Como executar

Instale Python 3 e clone o repositório:

```bash
git clone https://github.com/Fabr1n/ProjetoPython.git
cd ProjetoPython
python conta.py
```

Para abrir o Snake, execute `python teste01.py`. O jogo utiliza **W, A, S e D** para movimentação e precisa de um ambiente gráfico com suporte a Tk/Turtle.

Os scripts usam a biblioteca padrão do Python. São projetos de estudo; a simulação de conta não representa um sistema financeiro pronto para uso.

## Conceitos praticados

Classes e métodos · Entrada pelo terminal · Condicionais · Loops · Eventos de teclado · Coordenadas e colisões
